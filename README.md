## 核心功能亮点
1. **唯一纯粹规则（锁屏自动清零 · 开启重新计时）**：
   - 合上保护套或按电源键锁屏待机，**立即停止后台一切计时与闹钟并自动清零**，待机期间 0 唤醒、0 耗电；
   - 重新点亮屏幕或翻开保护套，**立即从头自动开始新一轮专注倒计时**；去掉所有繁杂冗余的规则切换。
2. **小猫跳出时纯粹无打扰**：
   - 专注倒计时结束进入休息时，全屏/透明层直接跳出**动态像素小黑猫与休息倒计时**，去掉所有乱七八糟的按钮与功能干扰，休息结束自动消失并开启下一轮专注。
3. **默认折叠隐藏的「时长设置 ▼」抽屉**：
   - 平时主屏只保留「暂停/继续」「重置」「时长设置 ▼」3 个按钮；
   - 展开抽屉后可调整工作/休息分钟数、**秒数刷新切换（仅分钟省电 / 分:秒每秒刷新）**、**音效模式切换**及**开启电池白名单**。
4. **全品牌安卓通用 & 防杀后台设置建议（设一次永久生效）**：
   - **汉王 (Clear6 / Clear7 / N10 等)**：在软件【时长设置 ▼】里点一下【开启电池白名单】选允许即可。
   - **文石 (BOOX 全系)**：除了点【开启电池白名单】外，长按桌面上的软件图标 → 点击「优化」 → 在「后台配置/冷冻设置」中**关闭「自动冻结后台」并设为「允许后台运行」**。
   - **墨案 / 海信 / 掌阅开放版 / 普通安卓手机平板**：点一下【开启电池白名单】或在最近任务界面给本软件加锁即可稳定运行。
