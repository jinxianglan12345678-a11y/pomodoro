* **版本号**：v1.0

## 核心功能亮点
1. **时长自由自定义**：
   - 支持一键切换常用预设（15分/5分、25分/5分、45分/10分、60分/10分）；
   - 支持通过 `工作 -5/+5分`、`休息 -1/+1分` 按钮自由微调专属专注与休息时长，自动本地记忆。
2. **双模式锁屏规则开关**：
   - **锁屏立即清零 · 解锁自动重开**：合上保护套或按电源键锁屏立即停止并清零当前进度，重新翻开保护套解锁自动开始新的一轮工作。
   - **锁屏后台继续计时 · 不清零**：熄屏待机时通过 CPU 唤醒锁在后台继续准时倒计时，适合息屏听课或闭目养神。
3. **内置墨水屏友好极简提示音**：
   - 内置「清脆嘀嗒」「木鱼短叩」「石英短鸣」「五度微铃」4 种毫秒级短促合成音效与无扬声器反色闪烁提醒。
4. **全系安卓电纸书通用**：
   - 适用于汉王 Clear6/Clear7/N10、文石 BOOX、墨案、掌阅、海信等所有开放式 Android 墨水屏设备，100% 纯离线运行。
